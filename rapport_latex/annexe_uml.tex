    \hline

    Admin consulte le dashboard de monitoring (Grafana/Prometheus). Suit : uptime, latence, FPS, taux d'erreur, logs système. Reçoit des alertes en cas de dépassement de seuils. & 
    Continu (alertes) \\

        \item Formulaire : URL RTSP, GPS, nom descriptif, type (route/carrefour).
        \item Test de connexion.
        \item Si OK : affiche le flux vidéo en live.
        \item Admin dessine la ROI (polygone interactif).
        \item Validation → Caméra active, détections commencent.
    \end{enumerate}

\section{2. Diagramme de Classe Détaillé}

\subsection{Vue d'ensemble}

L'architecture logicielle de CIRCULI est organisée en \textbf{4 couches} :
\begin{itemize}
    \item \textbf{Couche 1 : Acquisition} (Camera, VideoProcessor, ROI)
    \item \textbf{Couche 2 : Intelligence Artificielle} (YOLOv8Model, NMS, Detection)
    \item \textbf{Couche 3 : Données} (APIBackend, Database, Metrics)
    \item \textbf{Couche 4 : Alertes et Monitoring} (AlertManager, Logger)
\end{itemize}

\begin{figure}[H]
    \centering
    \fbox{\begin{minipage}{0.95\textwidth}
    \textbf{ARCHITECTURE COUCHES - VUE SYNTHÉTIQUE}
    
    \vspace{0.3cm}
    
    \begin{center}
    \begin{tabular}{|c|}
    \hline
    \textbf{COUCHE 1 : ACQUISITION} \\
    Camera RTSP / VideoProcessor / ROI \\
    \hline
    $\downarrow$ (Flux Frame) \\
    \hline
    \textbf{COUCHE 2 : INTELLIGENCE ARTIFICIELLE} \\
    YOLOv8Model / NMS Filter / Detection Objects \\
    \hline
    $\downarrow$ (Détections) \\
    \hline
    \textbf{COUCHE 3 : DONNÉES} \\
    APIBackend / Database (PostgreSQL) / Metrics \\
    \hline
    $\downarrow$ (KPI) \\
    \hline
    \textbf{COUCHE 4 : ALERTES \& MONITORING} \\
    AlertManager / Logger / Grafana \\
    \hline
    \end{tabular}
    \end{center}
    
    \end{minipage}}
    \label{fig:class-overview}
\end{figure}

\subsection{Sous-diagramme 2 : Détail du module d'inférence YOLOv8}

\begin{figure}[H]
    \centering
    \fbox{\begin{minipage}{0.95\textwidth}
    \textbf{SOUS-DIAGRAMME 2 : DÉTAIL MODULE INFÉRENCE YOLOV8}
    
    \vspace{0.5cm}
    
    \textit{Scénario : Zoom sur les étapes internes du modèle YOLOv8 + NMS.}
    
    \vspace{0.3cm}
    
    \begin{enumerate}
        \item[\textbf{Étape 1}] \textbf{Input Tensor} (640×640×3) : Image normalisée
        
        \item[\textbf{Étape 2}] \textbf{Backbone (YOLOv8)} : 
        \begin{itemize}
            \item Convolutions progressives (stride=2, 4, 8, 16, 32)
            \item Extraction de features multiples échelles
            \item Sortie : 4 cartes de features
        \end{itemize}
        
        \item[\textbf{Étape 3}] \textbf{Neck (FPN)} : 
        \begin{itemize}
            \item Fusion multi-échelle des features
            \item Pyramide de features (80×80, 40×40, 20×20)
        \end{itemize}
        
        \item[\textbf{Étape 4}] \textbf{Head (Détection)} :
        \begin{itemize}
            \item Chaque cellule de grille prédit :
            \begin{itemize}
                \item $(x, y, w, h)$ : coordonnées boîte
                \item $p$ : probabilité d'objet
                \item $(p_1, p_2, \ldots, p_C)$ : scores classe (C=3 : car, bus, truck)
            \end{itemize}
            \item Output shape : (Batch, 8400, 85) où 8400 = 80×80 + 40×40 + 20×20
        \end{itemize}
        
        \item[\textbf{Étape 5}] \textbf{Décodage des prédictions} :
        \begin{itemize}
            \item Conversion grille → pixels
            \item Filtrage confiance : conf $>$ 0.45 (élimine 70-80\% des boîtes)
        \end{itemize}
        
        \item[\textbf{Étape 6}] \textbf{NMS (Non-Maximum Suppression)} :
        \begin{itemize}
            \item Tri par confiance décroissante
            \item Pour chaque boîte conservée :
            \begin{itemize}
                \item Supprime toutes les boîtes chevauchantes
                \item $\text{IoU}(box_i, box_j) > 0.4$ → éliminer $box_j$
            \end{itemize}
            \item Sortie : liste finale (typi. 5-50 boîtes par frame)
        \end{itemize}
        
        \item[\textbf{Étape 7}] \textbf{Output final} : 
        \begin{itemize}
            \item list[Detection] avec (class, conf, bbox, area)
        \end{itemize}
    \end{enumerate}
    
    \vspace{0.3cm}
    
    \textbf{Complexité computationnelle} : ~2.5 GMACs (sur GPU/CPU)
    \textbf{Temps réel} : 52ms (CPU) / 8ms (GPU)
    
    \end{minipage}}
    \caption{Sous-diagramme 2 : Détail inférence YOLOv8}
    \label{fig:seq-yolo-detail}
\end{figure}

\subsection{Sous-diagramme 3 : Gestion des erreurs et résilience}

\begin{figure}[H]
    \centering
    \fbox{\begin{minipage}{0.95\textwidth}
    \textbf{SOUS-DIAGRAMME 3 : GESTION DES ERREURS ET RÉSILIENCE}
    
    \vspace{0.5cm}
    
    \textit{Scénario : Le flux RTSP s'interrompt → gestion automatique.}
    
    \vspace{0.3cm}
    
    \textbf{Cas 1 : Perte du flux RTSP (timeout)}
    
    \begin{enumerate}
        \item[\textbf{T0}] VideoProcessor attend frame de Camera
        \item[\textbf{T0+5s}] Timeout (pas de réponse) → Exception
        \item[\textbf{T0+5.1s}] Logger.error(« RTSP timeout », exception)
        \item[\textbf{T0+5.2s}] AlertManager.checkMetrics() → détecte anomalie
        \item[\textbf{T0+5.3s}] AlertManager.sendAlert() : Email + SMS aux admins
        \item[\textbf{T0+5.5s}] Airflow DAG : Exécute \texttt{retry\_task()} avec backoff exponentiel
        \item[\textbf{T0+6s}] Retry 1 : Nouvelle tentative de connexion
        \item[\textbf{T0+6.5s}] Si succès → Continue traitement normal
        \item[\textbf{T0+12s}] Si échec → Retry 2 (backoff=4s)
        \item[\textbf{T0+30s}] Si échec → Retry 3 (backoff=8s)
        \item[\textbf{T0+40s}] Après 3 échecs → Mark camera as ERROR
        \item[\textbf{T0+45s}] Dashboard affiche la caméra en rouge (INACTIVE)
    \end{enumerate}
    
    \vspace{0.3cm}
    
    \textbf{Cas 2 : Erreur de base de données (connection refused)}
    
    \begin{enumerate}
        \item[\textbf{T0+100ms}] Database.insert() échoue (connection\_error)
        \item[\textbf{T0+100.5ms}] APIBackend reçoit exception
        \item[\textbf{T0+101ms}] Retry avec exponentiel backoff (1s, 2s, 4s)
        \item[\textbf{T0+102ms}] Si échec → Cache les détections en mémoire (buffer)
        \item[\textbf{T0+30s}] Pool de connexion réessaie
        \item[\textbf{T0+32s}] Si Database revient online → Flush buffer
        \item[\textbf{T0+35s}] Toutes les détections persistées (ordre chronologique)
    \end{enumerate}
    
    \vspace{0.3cm}
    
    \textbf{Cas 3 : Erreur d'inférence (memory overflow)}
    
    \begin{enumerate}
        \item[\textbf{T0}] YOLOv8 reçoit Tensor de taille anormale
        \item[\textbf{T0+1ms}] Out of Memory → Exception
        \item[\textbf{T0+2ms}] Logger.critical(« GPU OOM »)
        \item[\textbf{T0+3ms}] AlertManager envoie alerte CRITIQUE
        \item[\textbf{T0+5ms}] Fallback : switch device CPU (plus lent mais stable)
        \item[\textbf{T0+100ms}] Inférence CPU (latence ↑ 52ms)
        \item[\textbf{T0+105ms}] Admin notifié pour upgrade GPU
    \end{enumerate}
    
    \end{minipage}}

\end{figure}
